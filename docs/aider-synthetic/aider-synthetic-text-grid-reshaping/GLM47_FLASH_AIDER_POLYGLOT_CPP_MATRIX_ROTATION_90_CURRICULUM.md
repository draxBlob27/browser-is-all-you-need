## Common visible boundary

All roots use C++17 and explicit, deterministic orientation conventions.
Rectangular dimensions swap after one clockwise quarter turn; signed Cartesian
coordinates use their documented origin; metadata such as headings, glyphs,
tile orientation, vector components, anchors, and neighbor relations must be
transformed with positions. Validation occurs before mutation. Invalid input
returns the documented invalid report and the sole mutating task leaves its
input unchanged.

The common topic does not authorize a common generic implementation. Each root
has a unique public API, representation, validation model, control flow,
observable diagnostic, and compilable false substitute. The private fixture
must reject the named shortcut after the shortcut compiles under the same
strict flags as the reference.

## Seven-dimension family gate

The owner rereads actual emitted docs, public headers, references, visible and
private tests, and negative implementations. It compares all 190 unordered
pairs separately across:

1. public API;
2. owned state or algorithm;
3. mutation and selection rules;
4. invalid and boundary behavior;
5. reference control flow;
6. deterministic oracle; and
7. topic-specific negative fixture.

The decision is conjunctive and derives only from the emitted docs, public API,
reference, visible/private tests, and compiled negative. Identifiers, literals,
task IDs, provenance, profile declarations, and clean-room domain names are
neutralized or excluded. Unique labels, profile strings, and unequal raw hashes
are not evidence. Independent focused tests must inspect every
per-dimension decision rather than trusting the top-level result.

The owner also materializes three non-counted coherent controls from emitted
roots: a domain/identifier rename, a constants/policy-only change, and an
opposite-end tie selection. Each must change real emitted files, build and pass

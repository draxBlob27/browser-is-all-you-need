## Public and prompt contracts

Each root owns a task-named C++17 header/source pair. Exact declarations,
value types, invalid/empty results, endpoint behavior, order, and ties are
emitted by `moonlight_offset_overlap_cases.py` and bound in each remedy spec.
Only `.docs/*.md` and the two declared solution files enter the prompt. Tests,
references, metadata, CMake, negatives, remedies, screens, and receipts remain
private. References map one-to-one to solutions by suffix and order.

Ranges are half-open; local values use the bounded fourteen-day horizon;
caller-supplied fixed offsets are whole minutes in `[-840, 840]`; normalization
subtracts the offset. Host clocks, DST/time-zone databases, files, network,
threads, randomness, shared policy switches, and bare overlap assignments are
forbidden.

## Tests and negatives

Every root has visible and private deterministic tests plus one strict,
compiling false source: wrong precedence, ignored closure, all-service
intersection, greedy non-augmenting allocation, ignored duty fragments,
overlap-only auction score, greedy reused handoff, ignored calibration,
count-instead-of-value scheduling, or UTC-day capacity. Reference and negative
run under the same tests and flags; the false executable must be rejected by
behavior, not by compilation or source inspection.

## Seven-dimension hard rule

The production evaluator rereads actual emitted docs, public API, reference,
visible/private tests, and topic-negative source. Each of all 45 pairs must
differ separately in `public_api`, `owned_state_or_algorithm`,
`mutation_selection_rules`, `invalid_boundary_behavior`,
`reference_control_flow`, `deterministic_oracle`, and
`topic_specific_negative_fixture`. The decision is conjunctive.

The v2 claim and receipt are archived and invalidated: its normalizer retained
domain/user identifiers, its 0.98 threshold was nondiscriminating, and relay
and support both used augmenting-path matching. V3 maps every user-defined and
domain identifier, literal, and endpoint direction to structural placeholders
while preserving type/arity, state relationships, control flow, invariants,
and assertions. Each recorded decision must remain below the per-dimension
0.80 clone threshold; no name, profile, raw hash, or aggregate score can pass a
pair.

A coherent copied-root domain/identifier rename, constants/policy-only change,
and opposite-end selection must each change emitted files, remain internally
consistent, compile, pass its adapted behavior tests, and be rejected by the
same evaluator in all seven dimensions. Focused tests independently inspect
the exact root/pair/dimension counts, every decision, nonempty mutations, and
control rejection rather than trusting a top-level result.

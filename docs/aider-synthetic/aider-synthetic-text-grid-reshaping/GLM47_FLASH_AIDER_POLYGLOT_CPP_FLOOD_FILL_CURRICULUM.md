## Binding rules

Each root owns a C++17 task-specific class and method, deterministic visit
order, explicit admission predicate, rectangular-input policy, no-op behavior,
immutable barrier rule, and diagnostic report. Work queues, stacks, and vectors
are incidental storage; a generic unrestricted four/eight-neighbor BFS is a
forbidden substitute. Private fixtures must execute that rejection path.

The owner must enforce one-to-one legacy/replacement mapping, materially
distinct public APIs and reference control flow, a complete 190-pair normalized
comparison of docs/API/reference/visible/private tests, the three mandatory
clone controls, prompt and role boundaries, exact reference mapping, compiled
and executed bad substitutes, clean normal and fresh ASan/UBSan execution,
whole-slug/content holdout screening, and a network-disabled locked receipt
before `local_family_verified`.
